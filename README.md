# DualCameraRecorder - 完全不公開授權給任何人使用
## 雙鏡頭錄影
- 雙鏡頭錄影 / 拍照
- 鏡頭可以放大 / 縮小
- 支援4K錄影
- 可切換前後鏡頭
- 子視窗可以移動 / 縮放 / 變換外形
- 長按可以快速錄影
- 可以切換閃光燈功能
- 長按可以對焦
